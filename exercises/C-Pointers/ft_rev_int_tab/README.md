Exercice: 5
ft_rev_int_tab
Répertoire: ex5/
Fichiers à Rendre: ft_rev_int_tab.c
Autorisé: None

- Créez une fonction qui inverse un tableau d'entiers donné (le premier
  devient le dernier, etc).
- Les arguments sont un pointeur sur un int et le nombre d'éléments dans
  le tableau.

Prototype :
void ft_rev_int_tab(int *tab, int size);
