Exercice: 4
ft_ultimate_div_mod
Répertoire: ex4/
Fichiers à Rendre: ft_ultimate_div_mod.c
Autorisé: None

- Créez une fonction ft_ultimate_div_mod qui divise le contenu pointé par
  a par celui pointé par b.
  - Le résultat est stocké dans l'entier pointé par a.
  - Le reste de la division est stocké dans l'entier pointé par b.

Prototype :
void ft_ultimate_div_mod(int *a, int *b);
