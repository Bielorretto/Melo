Exercice 3 : ft_div_mod

Exercice: 3
ft_div_mod
Répertoire: ex3/
Fichiers à Rendre: ft_div_mod.c
Autorisé: None

- Créez une fonction ft_div_mod qui divise le paramètre a par b et stocke
  le résultat dans l'entier pointé par div. Elle stocke également le
  reste de la division de a par b dans l'entier pointé par mod.

Prototype :
void ft_div_mod(int a, int b, int *div, int *mod);
