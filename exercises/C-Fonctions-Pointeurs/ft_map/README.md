Exercice 1 : ft_map

Exercice: 1
ft_map
Répertoire: ex1/
Fichiers à Rendre: ft_map.c
Autorisé: malloc

- Créez la fonction ft_map qui applique une fonction à chaque élément d'un
  tableau d'entiers et retourne un nouveau tableau avec les valeurs
  retournées.
- L'ordre doit être conservé.

Prototype :
int *ft_map(int *tab, int length, int(*f)(int));
