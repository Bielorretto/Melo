Exercice 2 : ft_any

Exercice: 2
ft_any
Répertoire: ex2/
Fichiers à Rendre: ft_any.c
Autorisé: None

- Créez la fonction ft_any qui retourne 1 si la fonction passée en
  paramètre retourne une valeur différente de 0 pour au moins une des
  chaînes du tableau. Sinon, elle retourne 0.
- Le tableau est terminé par un pointeur NULL.

Prototype :
int ft_any(char **tab, int(*f)(char*));
