Exercice 3 : ft_strjoin

Exercice: 3
ft_strjoin
Répertoire: ex3/
Fichiers à Rendre: ft_strjoin.c
Autorisé: malloc

- Ecrivez une fonction qui concatene toutes les chaines pointees par strs,
  separees par sep.
- size est le nombre de chaines dans strs.
- si size vaut 0, vous devez retourner une chaine vide que l'on peut
  free().

Prototype :
char *ft_strjoin(int size, char **strs, char *sep);
