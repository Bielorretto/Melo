Exercice 6 : ft_strlowcase

Exercice: 6
ft_strlowcase
Répertoire: ex6/
Fichiers à Rendre: ft_strlowcase.c
Autorisé: None

- Créez une fonction qui met en minuscule tous les caracteres
  alphabetiques d'une chaine, directement dans cette chaine (en place).
- Les caracteres non alphabetiques ne sont pas modifies.
- La fonction retourne la chaine modifiee.

Prototype :
char *ft_strlowcase(char *str);
