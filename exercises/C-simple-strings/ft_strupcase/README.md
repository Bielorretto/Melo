Exercice 5 : ft_strupcase

Exercice: 5
ft_strupcase
Répertoire: ex5/
Fichiers à Rendre: ft_strupcase.c
Autorisé: None

- Créez une fonction qui met en majuscule tous les caracteres
  alphabetiques d'une chaine, directement dans cette chaine (en place).
- Les caracteres non alphabetiques ne sont pas modifies.
- La fonction retourne la chaine modifiee.

Prototype :
char *ft_strupcase(char *str);
