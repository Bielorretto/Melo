# sort_int_tab

Fichiers à rendre : `sort_int_tab.c`
Autorisé : aucune

Écrivez la fonction suivante :

    void sort_int_tab(int *tab, unsigned int size);

Elle doit trier (sur place) le tableau d'entiers `tab`, qui contient
exactement `size` éléments, par ordre croissant.

Les doublons doivent être conservés.

L'entrée est toujours cohérente.
