Exercice 1 : ft_range

Exercice: 1
ft_range
Répertoire: ex1/
Fichiers à Rendre: ft_range.c
Autorisé: malloc

- Créez une fonction ft_range qui retourne un tableau d'entiers contenant
  toutes les valeurs entre min et max.
- min inclus, max exclu.
- Si min est superieur ou egal a max, un pointeur nul doit etre retourne.

Prototype :
int *ft_range(int min, int max);
